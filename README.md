# 勤怠Pro - 勤怠管理システム

## 概要
勤怠Proは、従業員の勤務時間を可視化・管理するためのWebアプリケーションです。
React RouterとFastAPIを使用した、モダンなフルスタックアプリケーションです。

## CSVデータ計算ロジック仕様

### 計算処理の概要
本システムは、CSVファイルから勤怠データを読み込み、各種計算処理を行って勤務時間を集計します。
計算ロジックは `/backend/app/services/csv_loader.py` に実装されています。

### 計算処理パターン一覧

#### 1. ステータスコード解析パターン

##### 1.1 基本ステータス
- **開始系**: `s`, `start`, `開始`
- **終了系**: `f`, `finish`, `end`, `終了`

##### 1.2 時間調整パターン
ステータスコードに調整時間を含めることで、実際の勤務時間を調整できます。

**プラス調整（+）**
- **`s+90`**: 開始時刻を90分前にずらす（早朝出勤など）
  - 例: 9:00に`s+90` → 実際の開始時刻は7:30として計算
- **`f+30`**: 終了時刻を30分後にずらす（残業など）
  - 例: 18:00に`f+30` → 実際の終了時刻は18:30として計算

**マイナス調整（-）**
- **`s-30`**: 開始時刻を30分後にずらす（遅れて出勤など）
  - 例: 9:00に`s-30` → 実際の開始時刻は9:30として計算
- **`f-60`**: 終了時刻を60分前にずらす（早退など）
  - 例: 18:00に`f-60` → 実際の終了時刻は17:00として計算

##### 1.3 調整情報の優先順位
1. **messageフィールド優先**: messageフィールドに調整情報がある場合、そちらを優先
2. **statusフィールド**: messageに情報がない場合、statusフィールドの調整情報を使用

#### 2. 日付調整パターン

##### 2.1 日跨ぎ処理（前日）
調整により時刻が負の値になった場合、前日の時刻として処理します。
- 例: 1:00に`s+120` → 前日の23:00として計算

##### 2.2 日跨ぎ処理（翌日）
調整により時刻が24時間を超えた場合、翌日の時刻として処理します。
- 例: 23:00に`f+120` → 翌日の1:00として計算

##### 2.3 深夜勤務の日跨ぎ
同日内で終了時刻が開始時刻より前の場合、自動的に日跨ぎとして処理します。
- 例: 22:00開始、2:00終了 → 4時間勤務として計算

#### 3. 勤務セッション計算パターン

##### 3.1 正常なセッション
- 開始（s）と終了（f）のペアが正しく存在する場合
- 計算式: `勤務時間 = 終了時刻 - 開始時刻`

##### 3.2 異常パターンの処理

**連続する開始時刻**
- 終了なしで次の開始が来た場合
- 処理: 警告を出力し、前のセッションを自動終了扱い

**開始なしの終了**
- 開始時刻なしで終了時刻が記録された場合
- 処理: 警告を出力し、その終了記録をスキップ

**未完了セッション**
- 開始のみで終了がない場合
- 処理: 情報として記録するが、勤務時間には含めない

#### 4. 異常値チェック

##### 4.1 24時間超過チェック
- 1つのセッションが24時間を超える場合
- 処理: エラーとして扱い、そのセッションを無効化

##### 4.2 日付逆転チェック
- 終了日が開始日より前の場合
- 処理: エラーとして扱い、そのセッションを無効化

#### 5. 集計パターン

##### 5.1 日別集計
- 各日の勤務時間を集計
- 同日に複数セッションがある場合は合計

##### 5.2 月別集計
- YYYY/MM形式で月ごとに勤務時間を集計
- 複数月にまたがる勤務も正しく振り分け

##### 5.3 総合計算
- 全期間の総勤務時間を計算
- 勤務日数をカウント

### データフォーマット

#### 入力CSVフォーマット
```csv
ユーザー,日付,時間,ステータス,メッセージ,合計稼働時間
田中太郎,2025/01/15,09:00,s,,
田中太郎,2025/01/15,18:30,f,,
山田花子,2025/01/15,08:00,s,s+60,
山田花子,2025/01/15,20:00,f,f+30,
```

#### 出力データ構造
```json
{
  "ユーザー名": {
    "name": "ユーザー名",
    "total_hours": 100,           // 総勤務時間（時）
    "total_minutes": 30,           // 総勤務時間（分の端数）
    "total_time_formatted": "100時間30分",
    "work_days": 15,               // 勤務日数
    "daily_hours": {               // 日別勤務時間
      "2025/01/15": {
        "hours": 8,
        "minutes": 30,
        "formatted": "8時間30分",
        "work_minutes": 510
      }
    },
    "monthly_hours": {             // 月別勤務時間
      "2025/01": {
        "hours": 160,
        "minutes": 45,
        "formatted": "160時間45分",
        "work_minutes": 9645
      }
    },
    "records": []                  // 各勤務セッションの詳細
  }
}
```

### 計算例

#### 例1: 基本的な勤務
- 開始: 2025/01/15 09:00 (s)
- 終了: 2025/01/15 18:00 (f)
- 計算: 18:00 - 09:00 = 9時間

#### 例2: 早朝出勤の調整
- 開始: 2025/01/15 09:00 (s+120)
- 終了: 2025/01/15 18:00 (f)
- 計算: 
  - 調整後開始: 09:00 - 120分 = 07:00
  - 勤務時間: 18:00 - 07:00 = 11時間

#### 例3: 深夜勤務（日跨ぎ）
- 開始: 2025/01/15 22:00 (s)
- 終了: 2025/01/16 06:00 (f)
- 計算: (24:00 - 22:00) + 06:00 = 8時間

#### 例4: 残業込みの勤務
- 開始: 2025/01/15 09:00 (s)
- 終了: 2025/01/15 18:00 (f+120)
- 計算:
  - 調整後終了: 18:00 + 120分 = 20:00
  - 勤務時間: 20:00 - 09:00 = 11時間

### エラーハンドリング

#### ログ出力
- **調整検出**: 時間調整が適用された場合
- **警告**: 連続開始、開始なし終了
- **エラー**: 24時間超過、日付逆転
- **情報**: 未完了セッション

#### データ整合性
- 不正なデータはスキップし、正常なデータのみ集計
- エラーログを出力して問題を可視化
- 部分的なエラーがあっても全体の処理は継続

## 主な機能

- **リアルタイム時計表示**: デジタル・アナログ時計
- **勤務時間グラフ**: 日別・月別の勤務時間推移を可視化
- **ユーザー別統計**: 15人までのユーザーの勤務データを同時表示
- **ダークモード対応**: ライト/ダークテーマの切り替え
- **自動データ更新**: 30秒ごとの自動更新機能

## セットアップ

### 必要な環境
- Node.js 18以上
- Python 3.8以上
- npm または yarn

### インストール

1. 依存関係のインストール
```bash
npm install
```

2. バックエンドサーバーの起動
```bash
cd backend
python -m uvicorn app.main:app --reload --port 8001
```

3. フロントエンド開発サーバーの起動
```bash
npm run dev
```

## 使用方法

1. ブラウザで `http://localhost:5173` にアクセス
2. ホーム画面で日別の勤務時間グラフを確認
3. 「履歴」ボタンで月別統計を表示
4. ユーザー名をクリックして個別の統計を強調表示
