# 勤怠Pro - 勤怠管理システム

## 📋 概要
勤怠Proは、従業員の勤務時間を可視化・管理するためのモダンなWebアプリケーションです。
React RouterとFastAPIを使用した、フルスタックアプリケーションです。

## ✨ 主な機能

### 📊 ダッシュボード
- **リアルタイム時計表示** - デジタル・アナログ時計
- **日別勤務時間グラフ** - 月単位での表示、過去月へのナビゲーション
- **ユーザー一覧** - 今月の勤務時間順で表示
- **月別統計** - ユーザー別の月次勤務時間推移

### ⏰ 勤怠管理
- **柔軟な時間調整** - `s+60`, `f-30` などの調整記法
- **直接時刻指定** - `s18:00`, `f19:30` で正確な時刻入力
- **日跨ぎ対応** - 深夜勤務も正確に計算
- **重複パターン処理** - s/s/f, s/f/f を自動処理

### 🎨 UI/UX機能
- **ダークモード** - ライト/ダークテーマの切り替え
- **プレミアムカラー** - 15色の洗練されたカラーパレット
- **レスポンシブデザイン** - 様々な画面サイズに対応
- **自動更新** - 30秒ごとのデータ自動更新

## 🚀 セットアップ

### 必要な環境
- Node.js 18以上
- Python 3.8以上
- npm または yarn

### インストール手順

#### 1. リポジトリのクローン
```bash
git clone [repository-url]
cd kintai
```

#### 2. フロントエンドのセットアップ
```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

#### 3. バックエンドのセットアップ
```bash
# バックエンドディレクトリに移動
cd backend

# 仮想環境の作成と有効化
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 依存関係のインストール
pip install -r requirements.txt

# サーバーの起動
python -m uvicorn main:app --reload --port 8001
```

## 📖 使用方法

1. ブラウザで `http://localhost:5173` にアクセス
2. ホーム画面で日別の勤務時間グラフを確認
3. 「履歴」ボタンで月別統計を表示
4. ユーザー名をクリックして個別の統計を確認

## 📊 データフォーマット

### CSVフォーマット
```csv
ユーザー,日付,時間,ステータス,メッセージ,合計稼働時間
田中太郎,2025/08/15,09:00,s,,
田中太郎,2025/08/15,18:00,f,,
```

### ステータスコード
- `s`, `start`, `開始` - 勤務開始
- `f`, `finish`, `end`, `終了` - 勤務終了

### 時間調整記法
- `s+60` - 開始時刻を60分前に調整
- `f-30` - 終了時刻を30分前に調整
- `s18:00` - 開始時刻を18:00に固定
- `f19:30` - 終了時刻を19:30に固定
