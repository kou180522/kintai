# App - フロントエンドディレクトリ

## 概要
このディレクトリはReact Routerベースのフロントエンドアプリケーションのソースコードを含みます。
TypeScriptとReactを使用して構築された、勤怠管理システムのユーザーインターフェースです。

## ディレクトリ構造

```
app/
├── components/         # 再利用可能なReactコンポーネント
│   ├── ui/            # shadcn/ui コンポーネント
│   ├── dashboard.tsx  # ダッシュボード（メイン画面）
│   ├── header.tsx     # ヘッダーコンポーネント
│   └── theme-*.tsx    # テーマ関連コンポーネント
├── routes/            # ページコンポーネント（ルーティング）
│   ├── home.tsx      # ホームページ
│   └── page2.tsx     # 履歴ページ
├── +types/            # TypeScript型定義
├── app.css           # グローバルスタイル
└── root.tsx          # アプリケーションのルートコンポーネント
```

## 主要コンポーネント

### Dashboard (`components/dashboard.tsx`)
- メイン画面のコンポーネント
- リアルタイム時計（デジタル・アナログ）
- 日別勤務時間グラフ
- ユーザー別統計表示
- 自動更新機能（30秒ごと）

### Header (`components/header.tsx`)
- アプリケーションヘッダー
- ナビゲーション（ホーム/履歴）
- テーマ切り替えボタン

### UIコンポーネント (`components/ui/`)
- shadcn/uiベースの再利用可能なコンポーネント
- Button, Card, Chart など

## 主な機能

1. **データ可視化**
   - Rechartsによるインタラクティブなグラフ
   - 15人分のユーザーデータを同時表示
   - ツールチップによる詳細情報表示

2. **リアルタイム更新**
   - 100msごとの時計更新
   - 30秒ごとのデータ自動取得

3. **ユーザーインタラクション**
   - ユーザー名クリックで強調表示
   - 月間合計時間のポップアップ表示
   - レスポンシブデザイン

4. **テーマ管理**
   - ダーク/ライトモードの切り替え
   - システム設定に従うオプション
   - スムーズなテーマ遷移アニメーション

## 使用技術

- **React 18+**: UIライブラリ
- **TypeScript**: 型安全な開発
- **Tailwind CSS**: ユーティリティファーストCSS
- **Recharts**: グラフ表示ライブラリ
- **shadcn/ui**: UIコンポーネントライブラリ

## 開発ガイド

### 新しいコンポーネントの追加
1. `components/`ディレクトリに新しいファイルを作成
2. TypeScriptで型定義を含めて実装
3. 必要に応じて`components/ui/`の既存コンポーネントを活用

### 新しいページの追加
1. `routes/`ディレクトリに新しいファイルを作成
2. React Routerの規約に従って実装
3. 必要に応じてルーティング設定を更新
