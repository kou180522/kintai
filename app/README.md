# app ディレクトリ

このディレクトリには、React Routerアプリケーションのメインソースコードが含まれています。

## ディレクトリ構造

```
app/
├── components/         # 再利用可能なUIコンポーネント
│   └── ui/            # shadcn/ui ベースのUIコンポーネント
├── hooks/             # カスタムReactフック
├── lib/               # ユーティリティ関数
├── routes/            # ルートコンポーネント
├── welcome/           # ウェルカムページ関連
├── root.tsx           # アプリケーションのルートコンポーネント
└── routes.ts          # ルート定義
```

## 主要ファイルの説明

### `root.tsx`
- アプリケーションのルートコンポーネント
- HTMLドキュメントの基本構造を定義
- グローバルスタイルシートの読み込み
- React Routerのアウトレットを含む

### `routes.ts`
- アプリケーションのルーティング設定
- 各ルートとコンポーネントのマッピングを定義

### `routes/home.tsx`
- ホームページのルートハンドラー
- `/` パスでアクセスされる
- Welcome コンポーネントをレンダリング

### `welcome/welcome.tsx`
- 勤怠管理システムのメインUI
- 現在は開発中で、React Routerのデフォルトウェルカムページが表示される
- 今後、以下の機能が実装される予定：
  - アナログ・デジタル時計表示
  - 出勤/退勤ボタン
  - 勤務時間の計測
  - 本日の勤務履歴表示
  - 社員の出勤状況一覧

## components/ui ディレクトリ

shadcn/uiライブラリのコンポーネントが含まれています。これらは再利用可能なUIコンポーネントで、Radix UIとTailwind CSSを基に構築されています。

主要なコンポーネント：
- `button.tsx` - ボタンコンポーネント
- `card.tsx` - カードレイアウト
- `dialog.tsx` - ダイアログ/モーダル
- `form.tsx` - フォーム関連コンポーネント
- その他多数のUIコンポーネント

## hooks ディレクトリ

### `use-mobile.ts`
- モバイルデバイスを検出するカスタムフック
- レスポンシブデザインの実装に使用

## lib ディレクトリ

### `utils.ts`
- ユーティリティ関数の集合
- Tailwind CSSのクラス名を結合する`cn`関数を含む
