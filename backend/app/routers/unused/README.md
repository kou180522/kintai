# Unused Routers - 未使用ルーター

## 概要
このディレクトリには現在使用されていないAPIルーターが保管されています。
将来的に機能を追加する際に参照・再利用できます。

## ファイル一覧

- **attendance.py**: 勤怠管理API（打刻機能）
- **colab_api.py**: Google Colab連携
- **sheets.py**: Google Sheets直接操作
- **slack.py**: Slack通知・連携
- **time_data.py**: 時間データ処理
- **users.py**: ユーザー管理
- **test.py**: テスト用エンドポイント

## 使用方法
必要に応じて、以下の手順で再有効化できます：

1. 必要なファイルを`../`（routersディレクトリ）に移動
2. `main.py`でルーターをインポート・登録
3. フロントエンドから該当エンドポイントを呼び出し

## 注意
これらのファイルは現在のシステムでは使用されていませんが、
コードの参考や将来の機能拡張のために保持されています。
