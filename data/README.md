# Data - データディレクトリ

## 概要
このディレクトリは勤怠管理システムで使用されるデータファイルとデータ処理スクリプトを含みます。

## ファイル説明

### CSVファイル
- **attendance_data.csv**: メインの勤怠データファイル
  - ユーザー名、日付、時刻、ステータス（s/f）を記録
  - 15人のユーザー、2000件以上の勤怠記録

### JSONファイル
- 勤務時間の集計結果
- 月別レポートデータ
- 検証結果

### Pythonスクリプト
- **calculate_*.py**: 勤務時間計算スクリプト
- **reload_data.py**: データ再読み込みスクリプト

## データ形式

### CSVフォーマット
```csv
ユーザー,日付,時刻,ステータス,メッセージ
山田太郎,2025/01/15,9:00,s,出勤
山田太郎,2025/01/15,18:30,f,退勤
```

### ステータスコード
- **s**: 勤務開始 (start)
- **f**: 勤務終了 (finish)
- **s+XX**: 開始時刻をXX分前に調整
- **f+XX**: 終了時刻をXX分後に調整

## データ更新

データファイルを更新した後、システムに反映させるには：
1. CSVファイルを編集
2. バックエンドサーバーを再起動
3. またはフロントエンドの「更新」ボタンをクリック

## 注意事項
- CSVファイルはUTF-8エンコーディングで保存
- 日付形式はYYYY/MM/DD
- 時刻形式はHH:MM
