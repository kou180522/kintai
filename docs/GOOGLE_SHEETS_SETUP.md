# Google スプレッドシート連携セットアップガイド

## 概要
このシステムは、Google スプレッドシートのユーザーマスタから自動的にユーザー情報を同期します。
スプレッドシートに新しいユーザーを追加すると、自動的にシステムに反映されます。

## セットアップ手順

### 1. Google スプレッドシートの準備

1. Google スプレッドシートを新規作成
2. シート名を「ユーザーマスタ」に変更
3. 以下の列を作成（1行目がヘッダー）：

| 名前 | 部署 | 役職 | メールアドレス | 社員番号 | ステータス |
|------|------|------|--------------|----------|-----------|
| 山田太郎 | 営業部 | 課長 | yamada@example.com | EMP_0001 | 有効 |
| 佐藤花子 | 開発部 | 一般社員 | sato@example.com | EMP_0002 | 有効 |
| 田中次郎 | 総務部 | 部長 | tanaka@example.com | EMP_0003 | 無効 |

**重要な列の説明：**
- **名前**（必須）: ユーザーの氏名
- **部署**: 所属部署（空欄の場合「未設定」）
- **役職**: 役職（空欄の場合「一般社員」）
- **メールアドレス**: メールアドレス
- **社員番号**: 社員番号（空欄の場合自動生成）
- **ステータス**: 「有効」または「無効」（無効にすると同期対象外）

### 2. スプレッドシートの公開設定

1. スプレッドシートの右上「共有」ボタンをクリック
2. 「リンクをコピー」をクリック
3. 「制限付き」を「リンクを知っている全員」に変更
4. 「閲覧者」権限で設定
5. URLからスプレッドシートIDを取得
   - URL例: `https://docs.google.com/spreadsheets/d/[スプレッドシートID]/edit`
   - `[スプレッドシートID]`の部分をコピー

### 3. Google API キーの取得

1. [Google Cloud Console](https://console.cloud.google.com/)にアクセス
2. プロジェクトを作成または選択
3. 「APIとサービス」→「認証情報」を開く
4. 「認証情報を作成」→「APIキー」を選択
5. 作成されたAPIキーをコピー
6. 「APIとサービス」→「ライブラリ」から「Google Sheets API」を有効化

### 4. 環境変数の設定

プロジェクトルートの`.env`ファイルに以下を追加：

```env
# 既存の設定
VITE_API_URL=http://localhost:8001

# Google Sheets連携設定
GOOGLE_SPREADSHEET_ID=あなたのスプレッドシートID
GOOGLE_API_KEY=あなたのAPIキー
SHEET_NAME=ユーザーマスタ
```

### 5. システムの再起動

```bash
# バックエンドサーバーを再起動
cd backend
pkill -f uvicorn
python3 -m uvicorn main:app --host 0.0.0.0 --port 8001 --reload
```

## 使用方法

### 手動同期

```bash
# APIエンドポイントを使用して手動同期
curl -X POST http://localhost:8001/api/sheets/sync/manual
```

### 自動同期の開始（5分間隔）

```bash
# 自動同期を開始（デフォルト300秒間隔）
curl -X POST http://localhost:8001/api/sheets/sync/auto/start?interval=300
```

### 自動同期の停止

```bash
curl -X POST http://localhost:8001/api/sheets/sync/auto/stop
```

### 同期ステータスの確認

```bash
curl http://localhost:8001/api/sheets/sync/status
```

## APIエンドポイント

- `POST /api/sheets/sync/manual` - 手動同期実行
- `GET /api/sheets/sync/status` - 同期ステータス確認
- `POST /api/sheets/sync/auto/start` - 自動同期開始
- `POST /api/sheets/sync/auto/stop` - 自動同期停止
- `POST /api/sheets/sync/configure` - 設定更新

## 動作の流れ

1. **スプレッドシートに新規ユーザー追加**
   - 名前、部署、役職などを入力
   - ステータスを「有効」に設定

2. **同期実行（手動または自動）**
   - システムがスプレッドシートを読み取り
   - 新規ユーザーを検出

3. **システムへの反映**
   - `data/users.json`にユーザー情報を保存
   - CSVファイルに初期エントリを追加
   - 勤怠管理システムで利用可能に

4. **ユーザーの無効化**
   - スプレッドシートでステータスを「無効」に変更
   - 次回同期時にシステムから除外

## トラブルシューティング

### スプレッドシートが読み込めない場合
- スプレッドシートの共有設定を確認
- APIキーが有効か確認
- Google Sheets APIが有効化されているか確認

### 同期されない場合
- `.env`ファイルの設定を確認
- サーバーログでエラーメッセージを確認
- スプレッドシートの列名が正しいか確認

### データ形式の注意点
- 名前は必須項目
- ステータスは「有効」または「無効」のみ
- 空欄の項目はデフォルト値が使用される

## 推奨事項

1. **定期的なバックアップ**
   - `data/users.json`を定期的にバックアップ
   - CSVファイルも別途保管

2. **アクセス権限の管理**
   - スプレッドシートの編集権限は管理者のみに制限
   - APIキーは安全に管理

3. **監視とログ**
   - 同期ログを定期的に確認
   - エラー発生時は速やかに対処
